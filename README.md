# Bubble Safari TV

لعبة عربية تعليمية خفيفة مصممة لشاشات Smart TV للأطفال من 2 إلى 5 سنوات.

## التحكم
- الأسهم: التنقل
- OK / Enter: اختيار
- Back / Escape: رجوع
- الصوت يمكن كتمه من داخل الجولة

## محتوى النسخة
- مستويان عمريان: 2–3 و4–5
- 12 جولة في كل مغامرة
- حيوانات، ألوان، أرقام، وأشكال
- تدرج صعوبة تلقائي
- نجوم وسلسلة نجاح وأفضل نتيجة محفوظة محليًا
- نطق عربي عبر Speech Synthesis عند توفر صوت عربي على الجهاز
- مؤثرات صوتية مولدة محليًا بدون ملفات صوت ثقيلة
- PWA + Offline cache
- واجهة 10-foot UI مناسبة للتلفزيون

## تشغيل محلي
افتح `index.html` عبر أي static web server.

مثال:
```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## النشر
المشروع Static بالكامل ويمكن نشره على GitHub Pages أو Cloudflare Pages دون Build step.

## الهدف التالي
تغليف نفس الواجهة كتطبيق Android TV وإضافة launcher banner/icon وملفات صوت عربية ثابتة قبل رفع المتجر.
