# Bubble Safari TV 🫧🌿

لعبة تعليمية عربية للأطفال من **2 إلى 5 سنوات**، مصممة من البداية لشاشات **Smart TV / Android TV / Google TV / Xiaomi TV Stick**.

## النسخة الحالية — MVP 0.1

- واجهة عربية Landscape مخصصة للتلفزيون.
- تحكم كامل بالريموت: الأسهم + OK/Enter + Back.
- مستويان عمريان: 2–3 و4–5 سنوات.
- 3 أنماط تحديات: الحيوانات، الألوان، والأرقام.
- 10 جولات في كل جلسة بدون Game Over أو عقوبات.
- نطق السؤال بالعربية عبر Speech Synthesis عندما يكون صوت عربي متاحًا على الجهاز.
- مؤثرات صوتية خفيفة مولّدة محليًا بدون ملفات صوت خارجية.
- Feedback إيجابي، نجوم، Confetti، وAnimations.
- تخزين محلي لأفضل تقدم وحالة كتم الصوت.
- PWA + Service Worker للعمل Offline بعد أول تحميل.
- لا Frameworks ثقيلة ولا Dependencies؛ مناسب للأجهزة الضعيفة.

## تشغيل محلي

يكفي تشغيل أي static server داخل مجلد المشروع، مثل:

```bash
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## التحكم

| الريموت / الكيبورد | الوظيفة |
|---|---|
| ↑ ↓ ← → | التنقل بين العناصر |
| OK / Enter | الاختيار |
| Back / Escape / Backspace | الرجوع |

## المرحلة التالية

1. اختبار واجهة النسخة الأولى على المتصفح والتلفزيون.
2. استبدال الرموز المؤقتة برسومات Animal Vector أصلية ومتسقة.
3. إضافة أصوات عربية مسجلة داخل التطبيق بدل الاعتماد على TTS الجهاز.
4. إضافة عوالم: الغابة، البحر، المزرعة، والفضاء.
5. إضافة Sticker Book ونظام مكافآت بسيط.
6. تغليف اللعبة كتطبيق Android TV وإضافة Leanback launcher/banner وأيقونة TV.
7. اختبار فعلي على Xiaomi TV Stick / Google TV ثم إخراج APK/AAB.

## مبادئ UX للأطفال

- لا Game Over.
- الخطأ لا ينقص نقاط الطفل.
- أهداف كبيرة وواضحة قابلة للاختيار من مسافة التلفزيون.
- نص قليل جدًا وصوت هو طريقة التوجيه الأساسية.
- لا إعلانات، مشتريات، أو روابط خارجية داخل تجربة الطفل.
