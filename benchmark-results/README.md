# Benchmark results

Generated benchmark artifacts live here and are intentionally separated by engine:

- `webview/<timestamp>/` — five cold + five warm WebView runs by default.
- `defold/<timestamp>/` — five cold + five warm Defold runs by default.
- `comparison/latest.json` — generated by `python3 benchmark/compare.py` after both sides have been measured.

Each run preserves raw Android evidence (`framestats.txt`, `gfxinfo.txt`, memory/CPU samples, SurfaceFlinger/GPU dumps, logcat) plus `summary.json`. Each timestamp directory also gets `aggregate.json` with median and P95 across runs.

Do not commit device result dumps by default; archive/share a selected comparison when making the Go/No-Go decision.
